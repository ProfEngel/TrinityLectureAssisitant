# Eve reference voice

The Eve voice sample is deliberately not stored in this public repository.
Voice samples can be biometric and personal data even when they were generated
with AI. Install a locally authorized sample with one of the Voice installers.

Expected runtime location:

```text
TrinityRuntime/voices/eve/Eve_Schule.mp3
```

The exact reference transcript is stored in `ref_text.txt`. Keep audio and text
paired. Do not replace either file without running `trinity voice doctor` and a
new listening test.

The example manifest documents the metadata that should accompany a locally
managed sample. It contains no voice data and no checksum from a private file.
