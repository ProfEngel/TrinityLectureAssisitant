# Skill: Simulation Agent

## Beschreibung
Rendert interaktive **HTML5/JavaScript-Simulationen** direkt im Content-Fenster. Ideal zur Visualisierung komplexer Konzepte live in der Vorlesung.

## Trigger-Wörter
`conway`, `game of life`, `simulation`, `zelluläre automaten`, `sierpinski`, `gravitationssimulation`, `neural network simulation`, `fourier`, `sort algorithmus`, `sortieralgori`

## Verfügbare Simulationen
| Befehl | Simulation |
|---|---|
| „Game of Life" / „Conway" | Conway's Game of Life (zelluläre Automaten) |
| „Sierpinski" | Sierpinski-Dreieck (Fraktal) |
| „Fourier" | Fourier-Reihen Visualisierung |
| „Sort Algorithmus" | Visualisierung von Sortieralgorithmen (z.B. Bubble Sort) |
| „Neural Network" | Einfaches neuronales Netz animiert (Forward Pass) |
| „Bienen" / „Bee" | Bienen-Ökosystem (Schwarmintelligenz mit Stöcken, Blumen, Fressfeinden) |
| „Raumzeitkrümmung" | Visualisierung einer Gravitationssenke |
| „Ameisen" / „Ant" | Langton's Ant (Zellulärer Automat) |
| „Pong" | Neuronales Pong (AI Training) |
| „Piraten" / „Fischer" | Spieltheorie: Räuber-Beute Modell (Lotka-Volterra) |

## Ausgabe
- **html_payload:** Vollständige interaktive HTML5/JS-Simulation im Content-Fenster (`KEEP_OPEN`)

## Beispiel-Sprachbefehle
- *„Trinity, zeig Conway's Game of Life"*
- *„Trinity, zeig die Bienen"*
- *„Trinity, starte die Fourier-Simulation"*
- *„Trinity, zeig einen Sort-Algorithmus"*
- *„Trinity, zeig das Neuronale Netz"*

## Abhängigkeiten
- Keine externen APIs – alles client-seitig in HTML/JS/Canvas
