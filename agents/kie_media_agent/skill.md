# kie.ai Medien

Gemeinsame Bild- und Musikgenerierung über kie.ai. Aktivierung über
`media_generation.provider = kie`. Geschützter Schlüssel im bestehenden
Workbench-Secretstore, nicht in Agentdateien oder auf mobilen Clients.
Bild: GPT Image 2.5 Flare, 2K, 16:9, deutsche Beschriftungen.
Musik: ai-music-api/generate, Suno V6, kurze Original-Demos.
Keine automatischen Provider-Fallbacks, keine Mermaid-Ausgabe.
