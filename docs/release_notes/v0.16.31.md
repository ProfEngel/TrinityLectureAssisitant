# v0.16.31 - Companion Antwortmodus und README-Aufraeumung

Dieses Release macht den lokalen Foundation-Fallback sichtbar steuerbar und
raeumt die Projektdokumentation weiter auf.

## Companion

- Neuer Antwortmodus-Schalter:
  - **Auto:** Trinity Server zuerst, Apple Foundation Models nur als lokaler
    Textfallback.
  - **Foundation:** einfache Textantworten bevorzugt lokal auf iPhone/iPad.
- Der aktive Antwortmotor wird oben in der Companion-App angezeigt.
- Lokal erzeugte Foundation-Antworten bleiben weiterhin Teil des Offline-Caches
  und werden spaeter ueber `/offline/events` zur Trinity-Session synchronisiert.

## Dokumentation

- Neue Feature-Uebersicht: `docs/FEATURE_OVERVIEW.md`.
- Neue Detaildoku fuer Offline-Cache, Sync und Foundation-Fallback:
  `docs/COMPANION_OFFLINE_SYNC.md`.
- README verweist frueh auf diese Unterdokumente und fuehrt nur noch die
  wichtigsten aktuellen Highlights direkt auf.

## Grenzen

Der Foundation-Modus ist absichtlich text-only. Agenten, Websuche, RAG,
Dateianalyse, Mediengenerierung und geplante Jobs benoetigen weiterhin eine
erreichbare Trinity-Serverinstanz.
