# Trinity v0.16.61 – Werkstatt-Start korrigiert

## Behoben

- Die Trinity-Werkstatt startet jetzt auch dann zusammen mit Trinity, wenn
  weder die WebUI noch die Companion-Bridge ausdrücklich aktiviert wurde.
- Trinity-App und Installationshinweis verwenden automatisch die tatsächlich
  konfigurierte lokale Bridge-Adresse. Eine Companion-Konfiguration auf Port
  8766 wird deshalb nicht mehr fälschlich unter Port 8765 gesucht.
- Ein App-Klick erkennt die bereits laufende Trinity-Instanz an dieser Adresse
  und öffnet direkt `#werkstatt`.
- Die Goose-Migration ersetzt nun auch einen historischen
  `default_brainvault_harness: goose` sowie einen möglichen Goose-Builder durch
  OpenCode.

## Prüfung

- vollständiger Python-Testbestand unter Python 3.13
- neue URL-Auswahltests für Server- und Companion-Betrieb
- macOS-App-/Installer-Tests
- JavaScript- und Shell-Syntaxprüfung
- Prüfung gegen eine reale Companion-Konfiguration auf Port 8766

Vault, Memory, RAG, Profile, Sessions, Soul und Benutzerkonfiguration bleiben
unverändert.
