# Release v0.8.2: Secure Pyodide WASM Sandbox for Data-Science & Mathematics 🧮

Dieses Release führt den neuen **Secure Sandbox Agent** ein. Trinity ist nun in der Lage, mathematische, statistische und datengetriebene Programmierungs-Aufgaben sicher in einer isolierten WebAssembly-Umgebung im Browser (QWebEngineView) auszuführen.

## 🚀 Neue Features

* **Secure WebAssembly Sandbox (Pyodide):**
  * Trinity führt generierten Python-Code ab sofort in einer sicheren, isolierten Pyodide-Laufzeitumgebung aus.
  * Da alles direkt im Browser läuft, hat bösartiger Schadcode **keinerlei Zugriff auf dein lokales Dateisystem oder deine Systemressourcen**.
  * Vollständig offline-fähig nach dem ersten Laden der WASM-Pakete.

* **High-End Data-Science Support:**
  * Kompatibel mit allen wissenschaftlichen Standard-Bibliotheken: **Numpy, Pandas, Matplotlib, Seaborn, SymPy, SciPy und Scikit-Learn**.
  * Trainiere AutoML-Modelle, vergleiche Genauigkeiten und führe komplexe statistische Berechnungen (z.B. Algebra, Integrale, Ableitungen) direkt lokal durch.

* **CORS-Bypass für globale Datensätze:**
  * Gezielte Aufhebung der CORS-Beschränkungen in PySide6 QWebEngineView.
  * Trinity kann nun jeden beliebigen Online-Datensatz (z.B. von GitHub oder APIs) direkt herunterladen und vorverarbeiten.

* **Interaktive Visualisierungen:**
  * Plotly wird nativ unterstützt. Trinity generiert **interaktive 3D- und 2D-Diagramme**, bei denen du im UI zoomen, filtern und über Datenpunkte hovern kannst.
  * Klassische Matplotlib/Seaborn-Visualisierungen werden automatisch abgefangen und als Base64-Bilder perfekt im UI gerendert.
