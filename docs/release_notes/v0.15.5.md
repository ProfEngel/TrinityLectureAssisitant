# Trinity Assistant v0.15.5

## Highlights

- Pi ist nun ein projektfaehiges Harness wie Codex/OpenCode.
- Pi unterstuetzt freigegebene Projekt-Aliasse, ein Standardprojekt und ein
  Arbeitsverzeichnis pro Lauf.
- Standard fuer die Pi-CLI ist `-p {prompt}`, damit Pi nicht interaktiv haengen
  bleibt.
- Settings UI, WebUI, CLI-Onboarding, Defaults und Tests wurden angepasst.

## Beispielkonfiguration

```text
SandboxVault = /vollstaendiger/Pfad/zur/Sandbox
TrinityVault = /vollstaendiger/Pfad/zum/Vault
```

Pi:

```text
Programm: pi
Argumente: -p {prompt}
Standardprojekt: SandboxVault
```

## Beispiel im Trinity-Chat

```text
Trinity, nutze Pi im Projekt SandboxVault. Pruefe den hello-agent: Welche Rechte
braucht er, welche Tests fehlen, und ist er sicher genug fuer Trinity?
```

## Grenze

Pi kann nur die Tools nutzen, die die installierte Pi-CLI beziehungsweise der
Pi-Wrapper bereitstellt. Trinity begrenzt Pi ueber Projekt-Aliasse und
Sicherheits-Prompt; produktive Agentenfreigaben bleiben weiterhin explizit.
