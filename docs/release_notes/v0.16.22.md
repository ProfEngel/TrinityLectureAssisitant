# v0.16.22 - Companion Control polish and macOS icon fix

## Highlights

- Companion Talk on iPhone now keeps camera and attachment controls above the bottom navigation from the first render.
- Companion Agents is interactive: agent favorites define the compact visible main-agent list, agents can be launched directly or prepared as chat prompts, and planned jobs get a guided prompt entry.
- Companion Control cards now open detail sheets for overview KPIs, RAG import, sessions/summaries, Memory and prompt drafts.
- Companion Settings on iPhone now contains live bridge URL, token, STT/TTS, audio-source and mic-threshold controls instead of only linking to the full settings sheet.
- macOS installer and app creator now reference `Trinity.icns` explicitly in the app bundle, so the Desktop/Finder app icon is shown before first launch.
- The iPhone/iPad Companion source is shipped as a separate release asset, so normal Trinity desktop installs stay lean.

## Verification

- `xcodebuild -project TrinityCompanion.xcodeproj -scheme TrinityCompanion -destination 'generic/platform=iOS Simulator' build`
- `python3 -m py_compile trinity_classic.py core/trinity_bridge.py`
