# v0.16.2 - Externe Harness-Agenten

## Neu

- `agentctl register` registriert vorhandene Projektordner, Markdown-Agenten,
  HTML-Werkzeuge, Python-Skripte und Harness-Konfigurationen als BrainVault-Agenten.
- Grosse Arbeitsordner werden nicht blind dupliziert, sondern sauber ueber
  `origin.source_paths`, `workspace` und `permissions` referenziert.
- Optional kann mit `--copy-source` ein kleiner Source-Snapshot im Agentenordner
  abgelegt werden.
- Die MainHub-Einstellungen enthalten jetzt eine explizite
  **Externe Harness-Agentenbasis (.agents)** fuer Codex, Pi, OpenCode,
  Antigravity und weitere Harnesses.

## Migration

- CampusHub- und Ideaverse-Quellen lassen sich strukturiert in
  `BrainVault/.agents` katalogisieren, ohne Trinity-interne Agenten oder
  Runtime-Daten zu vermischen.

## Validierung

- `agentctl validate` prueft zusaetzlich, ob referenzierte Ursprungspfade noch
  existieren.
