# v0.16.27 - Companion chat response compatibility

## Highlights

- Companion chat responses are now compatible with runtime paths that return an assistant event with the matching `request_id` but without a `session_id`.
- The mobile composer starts compact as a one-line input and grows only when more text is entered.
- New sessions still avoid stale events from older sessions; unscoped responses are only accepted when they match a pending request from the current app session.

## Verification

- `xcodebuild -project TrinityCompanion.xcodeproj -scheme TrinityCompanion -destination 'generic/platform=iOS Simulator' build`
