# v0.16.28 - Synchronized workspaces and sessions

## Highlights

- The Trinity Bridge now exposes workspace/session state through `/workspaces` and mutation endpoints for creating, renaming, pinning, archiving and deleting workspace sessions.
- `/events` accepts an optional `session_id`, so mobile clients can load the exact active session instead of only filtering the last global events locally.
- Unscoped assistant responses remain compatible with the mobile client when they match the active request flow.
- ClassicUI refreshes its workspace sidebar when workspace/session metadata changes on disk.

## Companion impact

- iPhone and iPad refresh workspace/session state from the Desktop Bridge when opening the app and when using the work-organisation sidebar.
- A session can be opened on Desktop, iPad or iPhone and then continued on another client with the same `session_id`.
- Mobile session actions such as create, rename, pin, archive and delete are pushed to the shared Bridge state.
- Long-running or parallel sessions no longer make older sessions appear empty just because newer global chat events exist.
