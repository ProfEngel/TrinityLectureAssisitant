# v0.10.1: Flexible UI & Headless Mode

Veröffentlicht am 15. Juni 2026.

Dieses Release trennt Trinitys Bedienoberfläche klarer vom Laufzeitkern. Bestehende
Installationen behalten die Augen-UI, können nun aber zusätzlich oder alternativ eine
klassische Desktop-App beziehungsweise eine Terminal-CLI verwenden.

## Enthalten

- Augen-UI als weiterhin unterstützte Oberfläche für Vorlesung und Präsentation
- neue Classic-UI mit Live-Mitschrift, Status, Ergebnisbereich und Texteingabe
- neue Terminal-CLI mit Logs, vollständigen Antworten und Texteingabe
- frei kombinierbare Oberflächen in `Einstellungen > System`
- automatischer Terminal-Fallback, wenn beide grafischen Oberflächen deaktiviert sind
- rückwärtskompatible Übernahme der bisherigen Terminal-Einstellung
- gemeinsamer Launcher für eine oder mehrere gleichzeitig aktive Oberflächen
- Windows-Verknüpfungen respektieren die gewählte Oberflächenkombination
- technische Grundlage für eine spätere Ubuntu- und Headless-Portierung

## Aktualisierung

macOS:

```bash
cd ~/Trinity_Assistant
git pull
```

Windows:

```powershell
cd $env:LOCALAPPDATA\Trinity
git pull
```

Unter Windows anschließend den Installer erneut ausführen, damit die normale
Verknüpfung die neue Oberflächenwahl berücksichtigt.

## Kompatibilität

- Der Funktionsumfang von macOS und Windows 11 bleibt erhalten.
- Ohne neue Konfiguration startet Trinity wie bisher mit der Augen-UI.
- `show_terminal` bleibt als ältere Konfigurationsoption lesbar.
