# Trinity v0.16.42 - Robuster Windows-Updater

## Behoben

- Beim Update konnte eine noch laufende Trinity-Instanz die Datei
  `logs\\launcher.log` sperren. Der Installer beendet nun gezielt Prozesse,
  deren Kommandozeile zur bestehenden Trinity-Installation gehoert.
- Das Entfernen der alten Installation wird bis zu fuenfmal versucht. Falls
  eine Fremdanwendung weiterhin sperrt, nennt der Installer die notwendige
  Aktion statt mit einem rohen `Remove-Item`-Fehler abzubrechen.

## Einmaliger Hinweis

Wenn ein aelterer Installer bereits an einer offenen `launcher.log` scheitert,
Trinity, offene Einstellungen und Diagnose-/Terminalfenster zuerst schliessen
und den Installer erneut ausfuehren. Nach diesem Update wird das automatisch
behandelt.
