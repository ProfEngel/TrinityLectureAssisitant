# v0.16.23 - Companion agents, prompts and theme polish

## Highlights

- Bridge `/dashboard` now exposes the full agent catalog to Companion clients instead of the first 80 records.
- New Bridge `/prompts` endpoint allows trusted Companion clients to load and save `Soul.md` and `User.md` directly.
- Companion Agents shows all dashboard agents and groups them as `Trinity-Kernagenten` and `BrainVault-Erweiterungen`.
- Companion agent favorites remain a view preference only: no agent is deleted or disabled when it is hidden.
- Companion Prompt control now loads the real desktop prompts and saves changes back through Trinity.
- Companion `System` / `Light` / `Dark` appearance setting now applies to both the compact Settings page and the full Settings sheet.

## Verification

- `python3 -m py_compile core/trinity_bridge.py trinity_classic.py`
- `xcodebuild -project TrinityCompanion.xcodeproj -scheme TrinityCompanion -destination 'generic/platform=iOS Simulator' build`
