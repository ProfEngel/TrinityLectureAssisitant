# Release Notes v0.4.5 - Stability & Responsiveness Update 🧞‍♀️

Dieses Update verbessert die Reaktionsgeschwindigkeit von Trinity und fügt Diagnose-Tools für das Mikrofon hinzu.

## 🚀 Highlights

- **Schnellere Reaktion**: `chunk_duration` wurde auf 2 Sekunden optimiert, damit Trinity schneller auf das Wake-Word reagiert.
- **Audio-Diagnose**: Das Terminal zeigt nun einen Live-Pegel (RMS) an, um sicherzustellen, dass das Mikrofon korrekt funktioniert.
- **JS-Stability**: Behebung eines Fehlers beim Initialisieren des Zustands-Managers im UI.
