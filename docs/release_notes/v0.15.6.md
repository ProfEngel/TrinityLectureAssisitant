# Trinity Assistant v0.15.6

## Harness Settings

- Harness-Statusmeldungen werden in den Einstellungen jetzt als kontrastreiche
  Status-Badges angezeigt, damit gefundene lokale Tools wie Codex, Pi und
  OpenCode im Dark Mode lesbar bleiben.
- Die Projektfelder fuer Codex, Pi und OpenCode sind hoeher, damit mehrere
  freigegebene Projekt-Aliasse leichter geprueft und editiert werden koennen.
- Die Agenten-/Harness-Matrix ist groesser, waechst im Fenster nach unten mit
  und nutzt alternierende Tabellenzeilen fuer bessere Orientierung.

## Pi Agent Import Safety

- Pi darf bei Import-Auftraegen explizit genannte Quellordner read-only
  analysieren.
- Schreibende Aktionen bleiben auf den freigegebenen Projektordner begrenzt,
  zum Beispiel `SandboxVault` oder `TrinityVault`.
- Das erleichtert kontrollierte Agentenimporte aus bestehenden Skill-Ordnern,
  ohne produktive Agenten oder externe Quellordner direkt zu veraendern.

## Empfohlener Test

```text
Trinity, nutze Pi im Projekt SandboxVault. Pruefe den importierten
document-reviewer-staging Agenten. Lies README, manifest.json, SECURITY und
TESTPLAN. Sage mir, ob er bereit fuer einen ersten isolierten Test ist und
welche Blocker bleiben.
```

## Sicherheit

- Importierte Agenten mit Dateisystem-, Netzwerk- oder Shell-Rechten sollten
  weiterhin zuerst in `SandboxVault` landen.
- Eine Promotion nach `TrinityVault` sollte erst nach Testplan, Security-Review
  und expliziter Freigabe erfolgen.
