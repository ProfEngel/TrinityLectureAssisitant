# v0.16.38 - Companion workspace remote fix and STT polish

Dieses Bugfix-Release stabilisiert die mobile Arbeitsorganisation und das
Talk-Gefuehl nach den grossen Workspace-/Session-Erweiterungen.

## Fixes

- iPhone/iPad-Companion-Clients duerfen Arbeitsraeume und Sessions jetzt wieder
  erstellen, umbenennen, archivieren und loeschen, sobald die Bridge-Anfrage
  grundsaetzlich authentifiziert ist. Eine bewusst offene Tailnet-Bridge ohne
  Bearer-Token blockiert diese Nutzeraktionen nicht mehr.
- Harte Systemeinstellungen bleiben separat geschuetzt: Ohne Token nur lokal,
  mit Accounts nur fuer Admins.
- Die Companion-App v0.16.40 zeigt Talk, Agent, Control, Chat, Vortrag und Web
  mit kompakter Statuszeile statt Debug-/STT-Texten im oberen Inhaltsbereich.
- Offene Trinity-Auftraege werden clientseitig sofort optimistisch sichtbar,
  nicht erst nachdem der Server eine finale Request-ID zurueckgegeben hat.
- Apple Speech bekommt zusaetzlichen Wakeword-Kontext fuer `Trinity` und nahe
  Varianten; finale STT-Chunks und Live-Updates reagieren etwas schneller.
