# Trinity v0.12.1 - Augen-UI Datei-Arbeitsbereich Fix

Dieses Bugfix-Release korrigiert den Datei-Arbeitsbereich der Augen-UI, ohne den bestehenden macOS- oder Windows-Funktionsumfang einzuschraenken.

## Behoben

- Abgelegte PDFs werden nicht mehr als leere weisse Seite ueber eine Webansicht geladen. Trinity zeigt stattdessen eine lesbare, extrahierte Textvorschau mit Dateinamen an.
- Neben der Vorschau steht jetzt **Im Standardprogramm oeffnen** bereit. Damit laesst sich eine PDF, Excel-Datei oder andere Anlage bewusst in der vom Betriebssystem zugeordneten Anwendung oeffnen.
- Antworten auf Fluestern-Auftraege im Arbeitsbereich werden direkt unterhalb der Eingabe eingeblendet. Die Antwort bleibt dabei weiterhin im normalen Chatverlauf erhalten.

## Testabdeckung

- Anlagen-Pipeline, PDF-/Textvorschau und Tabellenextraktion
- Workspace-Kontext
- Companion-Bridge und Laufzeitresilienz

Die Aenderung ist auf macOS und Windows identisch verfuegbar.
