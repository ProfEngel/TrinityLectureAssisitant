# v0.16.30 - Companion offline cache and local Foundation Models fallback

## Highlights

- Companion clients persist workspace/session/note state and per-session chat events locally, so the last known work organisation remains visible without a Trinity server connection.
- iPhone and iPad can answer simple text-only chat prompts locally through Apple's Foundation Models framework when the Trinity server is unreachable and the device supports it.
- Locally generated offline user/assistant events are kept in a sync buffer and uploaded back to Trinity once the Bridge is reachable again.
- The Bridge exposes `/offline/events` to import those offline Companion events into the server-side session history without duplicating already synced client events.

## Boundaries

- Offline mode intentionally does not run Trinity agents, web search, RAG, ComfyUI, media generation, file analysis or server-side automation.
- The local fallback requires iOS/iPadOS 26 with available Apple Intelligence/Foundation Models support; otherwise messages remain in the normal reconnect buffer.
