# v0.16.34 - Telegram session and Companion latency polish

Dieses Bugfix-Release stabilisiert die Kommunikationskanaele nach dem grossen
Arbeitsraum-/Offline-Fallback-Ausbau.

## Highlights

- Telegram nutzt nun eine feste Session `Telegram`. Textnachrichten,
  Sprachnachrichten und Telegram-Bilder werden dadurch nicht mehr in zufaellige
  Desktop- oder Companion-Sessions gemischt.
- Telegram-Anfragen erzeugen weiterhin Telegram-Antworten. Lokal generierte
  Medien koennen im Telegram-Kanal erscheinen, ohne die aktive iPad-/iPhone-
  Session zu verunreinigen.
- Companion-Clients wurden passend dazu geglaettet: kompaktere iPhone-Status-
  zeilen, mehr Platz fuer Kamera/Anhang im Talk-Modus, schnellere Rueckkehr zur
  STT-Konversation nach lokaler TTS und sofortiges lokales Anzeigen neu
  angelegter Arbeitsraeume/Sessions.

## Geprueft

- `PYTHONPATH="$PWD/core:$PWD" python3 -m py_compile core/transcriber.py`
- `PYTHONPATH="$PWD/core:$PWD" python3 -m pytest -q`
