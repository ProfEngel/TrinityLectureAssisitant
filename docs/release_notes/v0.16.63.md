# Trinity v0.16.63 – Werkstatt profilunabhängig

## Geändert

- Die Trinity-Werkstatt ist vorerst in **Arbeit/BIZ**, **Privat/PRIVAT** und
  **Development/TEST** gleichermaßen nutzbar.
- Die Gutachter-Kachel wird in allen drei Profilen als bereit angezeigt und
  kann überall gestartet werden.
- Das aktive Profil bleibt gut sichtbar und wird im Auftrag protokolliert,
  verursacht aber keine automatische Zugriffssperre.

## Künftige Ordnung

Agenten können später in verständliche Kategorien wie „Geschäftlich“,
„Privat“, „Lehre“, „Schreiben“ oder „Organisation“ einsortiert werden. Diese
Kategorien dienen zunächst der Übersicht. Eine echte Einschränkung wird nur
dann ergänzt, wenn sie später für einen konkreten Agenten ausdrücklich
festgelegt wird.

## Prüfung

- Katalogtests für BIZ, PRIVAT und TEST
- vollständiger Python-Testbestand unter Python 3.13
- lokale Prüfung der installierten PRIVAT-Werkstatt
- macOS- und Windows-CI

Vault, Profile, Sessions, Memory, RAG, Soul und Benutzerkonfiguration bleiben
unverändert.
