# Trinity v0.16.12

Kleines Subrelease fuer oeffentliche Dokumentation und Session-Benennung.

## Aenderungen

- GitHub-Markdown-Dokumentation wurde von sensiblen Dokumentanalyse-Beispielen
  auf neutrale Projekt-, Dokument- und Feedbackbeispiele umgestellt.
- ClassicUI schlaegt bei `Neue Session` nun automatisch
  `JJJJMMDD_HHMM_` vor, sodass nur noch ein sprechender Zusatz ergaenzt werden
  muss.
- WebUI nutzt denselben Sessionnamen-Prefix.
- Die Companion-App nutzt denselben Prefix fuer iPhone und iPad.

## Pruefung

- Versionierte Markdown-Dateien wurden auf entfernte sensible Beispielbegriffe
  geprueft.
- Python-Dateien wurden kompiliert.
- Der WebUI-Sessionnamen-Prefix wurde im gerenderten HTML geprueft.
