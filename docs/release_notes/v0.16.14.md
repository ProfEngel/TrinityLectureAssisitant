# Trinity v0.16.14

## Pi Desktop Launcher Fix

- Stabilisiert den Start von Homebrew-/Node-basierten Pi-CLIs aus der Trinity Desktop-App.
- Pi-Unterprozesse erhalten nun einen erweiterten `PATH` mit Homebrew-, lokalen und Systempfaden.
- Behebt den Fehler `env: node: No such file or directory`, der auftreten konnte, wenn Trinity nicht aus einer Login-Shell, sondern per App-/Command-Launcher gestartet wurde.
