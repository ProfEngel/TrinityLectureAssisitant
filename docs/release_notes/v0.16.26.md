# v0.16.26 - Companion chat cleanup bridge

## Highlights

- New Bridge endpoint `/event/delete` removes a single chat event from the shared Trinity chat history.
- `chat_protocol.remove_chat_event()` rewrites the JSONL history atomically so deleted messages do not reappear after reconnects.
- Desktop tests cover single-message deletion at protocol and Bridge level.

## Companion impact

- The Companion app can now delete individual chat messages "for all" through the Bridge.
- New Companion sessions no longer rehydrate stale events from earlier sessions because the mobile client filters events by the active `session_id`.
- Return-to-send behavior is supported by the Companion composer, with multiline input still available through the multiline field behavior.
