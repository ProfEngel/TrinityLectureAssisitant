# Trinity v0.11.4

Dieses Subrelease stabilisiert die Companion-Bridge für gesprochene iPhone-/iPad-
Anfragen an Trinity Desktop.

## Fix

- Finale Companion-STT-Sätze werden nicht mehr versehentlich verworfen, wenn kurz
  zuvor dasselbe Fragment bereits als Live-STT eingegangen ist.
- Die Desktop-STT-Verarbeitung unterscheidet nun explizit zwischen Live-Fragmenten
  und finalen STT-Sätzen. Doppelte Live-Fragmente werden weiterhin unterdrückt,
  finale Sätze dürfen aber immer den Wake-Word-/Chat-Trigger auslösen.
- Damit reagieren gesprochene Companion-Anfragen wie
  `Trinity, erklär mir Spieltheorie` wieder zuverlässig, auch wenn die iPhone-App
  denselben Text zunächst live und danach final sendet.

## Dokumentation

- README um den aktuellen Stand der iPhone/iPad Companion-App ergänzt:
  lokales iPhone-STT, lokales iPhone-TTS, Alltagsansicht, Chat-/Live-Ansicht,
  Anlagen, Medienvollansicht, neue Sessions und Tailscale-Bridge.
- README weist auf die iOS-Grenzen lokaler Speech Recognition im Hintergrund hin
  und beschreibt die langfristig robustere Desktop-Transkriptionsarchitektur.

## Kompatibilität

- Keine Einschränkung der bestehenden macOS-Funktionen.
- Windows 11 bleibt unverändert unterstützt.
- Die Änderung betrifft die Desktop-Trinity-Verarbeitung externer Companion-STT-
  Events. Die Companion-App muss für diesen Fix nicht zwingend neu installiert
  werden; Trinity Desktop sollte nach dem Update neu gestartet werden.
