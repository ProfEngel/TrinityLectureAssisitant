# Trinity v0.11.5

Dieses Subrelease stabilisiert den Companion-Medienabruf für iPhone und iPad,
wenn Trinity Desktop auf macOS oder Windows 11 läuft.

## Fix

- Windows-Medienpfade aus generierten Bild-/Audio-/Video-Payloads werden nun
  korrekt normalisiert. Insbesondere werden Bridge-Anfragen wie
  `/media?path=/C:/Users/...` zuverlässig zu `C:/Users/...` aufgelöst.
- `file://`-Quellen aus macOS-Payloads werden weiterhin über erlaubte
  Medienwurzeln (`gen_images`, ComfyUI-Medienordner, `memory`) validiert und als
  Companion-taugliche `/media`-URLs ausgeliefert.
- Fehlerhafte oder nicht freigegebene Medienpfade werden weiterhin abgewiesen,
  damit die Bridge keine beliebigen Dateien vom Desktop ausliefert.

## Kompatibilität

- Keine Einschränkung der bestehenden macOS-Funktionen.
- Windows 11 erhält denselben Companion-Medienpfad wie macOS.
- iPhone/iPad Companion-Clients profitieren automatisch, sobald Trinity Desktop
  mit dieser Version läuft und die Bridge neu gestartet wurde.

## Prüfung

- `python3 -m pytest tests/test_trinity_bridge.py`
- Regressionstest für Windows-Drive-Pfade aus Companion-Media-URLs ergänzt.
