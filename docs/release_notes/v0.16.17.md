# Trinity v0.16.17

## Arbeitsraeume und Sessions: Foundation

- Neue lokale Runtime-Schicht `core/workspace_manager.py`.
- Trinity legt jetzt eine lokale Arbeitsorganisation unter
  `TrinityRuntime/workspaces/` an.
- `_inbox` ist der Standard-Arbeitsraum fuer Schnellsessions.
- Sessions erhalten eigene `session.json`, `events.jsonl`, `transcript.md` und
  einen Medienordner.
- Sessions koennen zwischen Arbeitsraeumen verschoben werden.

## CLI

Neue Kommandos:

```bash
trinity workspace status
trinity workspace list
trinity workspace create "Erendria" --kind writing --pinned

trinity session new --workspace _inbox --title 20260701_1430_Kapitel3
trinity session list
trinity session move SESSION_ID --workspace erendria
```

## ClassicUI

- Die Haupttabs sind jetzt auf `Alltag`, `Vortrag`, `Web`, `Chat` und `Live`
  reduziert.
- `Presenter` ist kein eigener Haupttab mehr; grosse Medien bleiben als
  Ergebnis-/Overlay-Prinzip vorgesehen.
- Die Arbeitsorganisation ist links neben allen Hauptansichten ein- und
  ausklappbar.
- Neue Desktop-Sessions werden in der lokalen `_inbox` registriert.
- Die linke Leiste zeigt bereits echte Arbeitsraeume und Sessions aus der
  lokalen Runtime.

## Memory

- Memory-/Graph-Ansicht ist aus `Live` herausgezogen.
- In den Einstellungen gibt es nun einen eigenen `Memory`-Tab mit Status,
  `Memory backen` und `Graph aktualisieren`.

## Roadmap

- Die neue Roadmap
  `docs/WORKSPACES_SESSIONS_NOTES_ROADMAP.md` beschreibt das Zielbild fuer
  Arbeitsraeume, Sessions, Schnellsessions, Notizen, Summaries und
  Cross-Workspace-Jobs.
- Die Roadmap haelt fest, dass ClassicUI, WebUI, iPad und iPhone dieselbe
  einklappbare Arbeitsorganisation erhalten sollen.

## Companion-App

- Die lokale iPhone-/iPad-Companion-App wurde parallel vorbereitet:
  Arbeitsorga-Button, iPad-Sidebar, iPhone-Drawer und Wegfall von `Presenter`
  als Hauptansicht.
- Hinweis: Die Companion-App liegt aktuell ausserhalb dieses Git-Repos und ist
  daher nicht Bestandteil dieses GitHub-Commits.
