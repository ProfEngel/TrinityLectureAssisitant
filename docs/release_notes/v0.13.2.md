# Trinity v0.13.2 - WebUI als Desktop-Oberflaeche

## Neu

- Die Browser-WebUI ist auf macOS und Windows 11 als vierte Oberflaeche neben Augen-UI, Classic-UI und Terminal waehbar.
- Aktivierung in **Einstellungen > System > Bedienoberflaechen** oder direkt mit `trinity start --surface web`.
- `trinity start --surface all` startet alle vier Oberflaechen.
- Beim aktivierten WebUI-Modus startet Trinity die Bridge mit dem Kern und oeffnet den Standardbrowser auf `http://127.0.0.1:8765/`.
- WebUI darf die einzige sichtbare Oberflaeche sein; die Terminal-CLI wird nur noch erzwungen, wenn Augen-, Classic- und WebUI zugleich deaktiviert sind.
