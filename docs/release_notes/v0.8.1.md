# Release v0.8.1: Trinity Chat-Mode & Dynamic Mode Switching 💬

Dieses Release führt den neuen **Chat-Modus** ein und ermöglicht das nahtlose Wechseln zwischen verschiedenen Operationsmodi, ohne dass die Trinity-App neu gestartet werden muss. Der Fokus dieses Updates liegt auf extremer Ressourcenschonung für Desktop-Nutzer.

## 🚀 Neue Features

* **Ressourcenschonender Chat-Modus:**
  * Im neuen Basis-Chat-Modus bleiben das Mikrofon (STT via Whisper oder Apple Native) und die Sprachausgabe (TTS) vollständig deaktiviert.
  * Trinity kommuniziert rein textbasiert über die UI oder via Telegram.
  * Das schont die CPU-Ressourcen und den Akku auf Laptops enorm.

* **Dynamische Modus-Umschaltung (Live-Toggle):**
  * Du kannst Trinity jetzt jederzeit über die UI oder per Sprache anweisen, den Modus zu wechseln ("wechsle in den büromodus", "wechsle in den chatmodus").
  * Das System startet oder stoppt die lokalen Audio-Streams **nahtlos im Hintergrund**. Ein App-Neustart ist nicht mehr notwendig.

* **Sauberes Session-Logging:**
  * Alle Chat-Eingaben via UI (`SILENT:`-Befehle) werden nun nahtlos als `[User (UI-Chat)]` in der Session-Historie mitgeschrieben.
  * Das Format der Protokolldateien wurde auf `raw_session_ddmmmyyyy_hhmm.md` (z.B. `raw_session_17May2026_1507.md`) umgestellt, um den Anforderungen für das spätere RAG-Postprocessing noch besser zu entsprechen.

## 🛠 Verbesserungen & Bugfixes

* Der Modus kann jetzt bequem im Einstellungen-Menü der Trinity-UI ausgewählt werden.
* Wenn der Modus per Command Line / Telegram geändert wird, aktualisiert sich automatisch die `config.json`.
