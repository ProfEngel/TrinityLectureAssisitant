# Trinity v0.11.7

Dieses Subrelease erweitert die Companion-Bridge fuer iPhone/iPad-Setups mit
Trinity Desktop auf macOS oder Windows 11.

## Fix

- Die Bridge gibt nun auch den lokalen `core/`-Ordner als kontrollierten
  Medienwurzelpfad frei.
- Dadurch koennen Agentenresultate aus `core/payload.html`, z.B.
  `core/sandbox_screenshot.png`, ueber `/media` an die Companion-App ausgeliefert
  werden.
- Das ermoeglicht Overlays und Presenter-Anzeigen fuer Pyodide-/Python-Sandbox,
  Plotly-Diagramme, Timer-Widgets und Simulationen, sofern die Companion-App den
  aktuellen Rich-HTML-Overlay-Stand nutzt.

## Kompatibilitaet

- Keine Einschraenkung der bestehenden macOS-Funktionen.
- Windows 11 bleibt unveraendert unterstuetzt; der neue Medienwurzelpfad ist
  plattformneutral.
- Aus Sicherheitsgruenden bleibt die Bridge weiterhin auf definierte Trinity-
  Laufzeitordner beschraenkt und liefert keine beliebigen Dateien vom Desktop aus.

## Pruefung

- `python3 -m py_compile core/trinity_bridge.py`
- `PYTHONPATH="$PWD/core:$PWD" python3 -m pytest tests/test_trinity_bridge.py`
