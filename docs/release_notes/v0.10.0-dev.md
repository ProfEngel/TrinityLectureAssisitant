# v0.10.0-dev: Windows 11 Platform Foundation

Diese Entwicklungsversion ergänzt Windows 11 additiv. Der bisherige macOS-Funktionsumfang
bleibt erhalten und ist separat als Release `v0.9.2` gesichert.

## Enthalten

- Plattformadapter für macOS und Windows
- macOS `say` und Windows SAPI hinter einer gemeinsamen TTS-Schnittstelle
- abbrechbare TTS-Ausgabe auf beiden Plattformen
- PowerPoint über AppleScript auf macOS und COM auf Windows
- Capability-Erkennung für systemabhängige Agenten
- klare Deaktivierung nicht verfügbarer Funktionen
- portable Temp-Dateien und Python-Unterprozesse
- Windows-PowerShell-Installer
- Python-Auswahl mit Versions- und SSL-Prüfung
- automatische Python-3.11-Installation oder -Reparatur über `winget`
- zuverlässige Maus- und Tastatureingabe am schwebenden Trinity-Fenster unter Windows
- Rechtsklick auf Trinity öffnet die Einstellungen direkt
- stabiler Windows-Textbetrieb ohne vorzeitiges Laden von Whisper oder Mikrofon
- sichtbarer LLM-Verbindungstest in den Einstellungen
- dauerhafte Laufzeit-, UI- und Starter-Protokolle im Ordner `logs`
- Diagnosefenster statt vollständigem Beenden bei einem Kernprozessfehler
- zentrale Abhängigkeiten über `pyproject.toml`
- Smoke-Tests für macOS und Windows

## Bewusst ausstehend

- Microsoft-Graph-Anmeldung für das neue Outlook
- Hardwaretests des Audio-Routings auf unterschiedlichen Windows-Geräten
- signierter Windows-Installer
- finales Windows-Release
