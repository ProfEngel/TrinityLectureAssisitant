# Trinity v0.11.3

Dieses Subrelease verfeinert den Hellmodus in der SettingsUI.

## Verbesserungen

- Eingabefelder, Textbereiche, Dropdowns und Zahlenfelder verwenden im Hellmodus nun helle Flächen mit dunkler Schrift.
- Tabs, Gruppenrahmen, Buttons, Auswahlfarben und Scrollbars folgen der hellen Farbpalette der ClassicUI.
- Die eingebettete Settings-Seite wird beim Öffnen und beim Dark-/Light-Wechsel live mit dem aktuellen ClassicUI-Theme synchronisiert.

## Kompatibilität

- Keine Einschränkung der bestehenden macOS-Funktionen.
- Windows 11 bleibt unverändert unterstützt; die Änderung betrifft ausschließlich UI-Farben und Theme-Synchronisierung.

## Prüfung

- `python3 -m compileall core/settings_ui.py trinity_classic.py`
- `python3 -m pytest $(git ls-files 'tests/test*.py')`
- GitHub Smoke Checks für macOS und Windows
