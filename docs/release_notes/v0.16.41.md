# Trinity v0.16.41 - Windows Einstellungen-Bugfix

## Behoben

- Der Einstellungen-Dialog konnte unter Windows beim Aufbau des
  **Harnesses**-Tabs abstuerzen. Ursache war eine Projektlisten-Hilfsfunktion,
  die als Instanzmethode statt als statische Hilfsfunktion definiert war.
- Codex-, Pi-, Goose- und OpenCode-Projektlisten werden beim Oeffnen der
  Einstellungen wieder korrekt dargestellt.

## Pruefung

- Der Einstellungen-Dialog wurde als Offscreen-UI geoeffnet.
- Die vollstaendige Desktop-Testauswahl lief erfolgreich durch.
