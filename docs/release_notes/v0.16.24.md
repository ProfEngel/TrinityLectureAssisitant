# v0.16.24 - Agent details, session delete and UI alignment

## Highlights

- Bridge `/dashboard` exposes richer agent metadata for desktop and Companion clients: origin, description, rights, paths, approval hints, risk level and job counters.
- New Bridge `/agent/update` endpoint stores a non-destructive display name override, so agents can be renamed in the UI without changing their folders.
- New Bridge `/session/delete` endpoint and ClassicUI sidebar action remove workspace sessions when they are no longer needed.
- ClassicUI uses a more iPad-like top toolbar with compact icon clusters for workspace, listening, new session, mode, audio source, TTS, theme and settings.
- Companion Agent cards show Trinity vs. BrainVault origin, short description, rights and job status, and support display-name edits through the Bridge.
- Companion chat input now uses a modern rounded composer surface on iPhone and iPad.

## Notes

- Agent scheduling and agent creation are prepared through the Agent/Control surfaces and existing Codex/Pi harness routing. A persistent scheduler/queue daemon remains a separate next implementation step before daily timed jobs can run unattended.
