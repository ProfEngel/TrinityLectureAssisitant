# Trinity v0.17.1

This maintenance release hardens local Eve conversations on macOS and Windows.

## Fixed

- Microphone input and speaker output now use independent PortAudio streams.
  This avoids a blocking duplex open when the two devices expose different
  native sample rates, a common macOS configuration.
- Distinct user speech detected during playback immediately clears buffered Eve
  audio and sends `response.cancel`. Server VAD remains active as a second
  interruption path.
- Echo correlation and the configurable barge-in level remain in place so open
  speakers do not normally cancel Eve with her own voice.

## Compatibility

- Existing Eve models, reference voice, external LLM settings and profiles are
  preserved.
- `Legacy` remains available manually and as the automatic failure fallback.
- Companion v0.17.0 is protocol-compatible; no mobile reinstall is required for
  this desktop-only audio-device fix.
