# Trinity v0.12.0 - Arbeitsbereich und Linux Web Server

## Neu

- Dateien koennen auf die Augen-UI gezogen werden. Trinity oeffnet einen Arbeitsbereich mit Vorschau und haelt die Datei als aktiven Kontext fuer Sprach- und Fluesteraustraege.
- PDF, Bild, Text sowie Excel `.xlsx` und `.xlsm` werden als Chat-Anlagen verarbeitet. Tabelleninhalte werden lokal extrahiert und dem Modell strukturiert uebergeben.
- Die Classic-UI akzeptiert Excel-Dateien nun ebenfalls ueber Anlage und Drag-and-drop.
- Neuer Befehl `trinity server`: Startet den Headless-Kern mit browserbasierter WebUI ohne PySide oder lokale Spracheingabe.
- Die WebUI wird vom vorhandenen Bridge-Server ausgeliefert und bietet Token-Anmeldung, Chat, Datei-Upload, Medienanzeige und HTML-/Sandbox-Payloads.
- Neuer Linux-Installer `install_linux.sh` und Deployment-Anleitung fuer Ubuntu/Linux.

## Kompatibilitaet

- macOS- und Windows-Installationen behalten ihre Oberflaechen und Einstellungen unveraendert.
- Die Desktop-Extras bleiben in den macOS-/Windows-Abhaengigkeiten; Linux installiert keine PySide-Desktop-UI.
- Die Linux-WebUI ist fuer lokale Nutzung oder private Tailscale-Netze vorgesehen.

## Validierung

- `python3 -m compileall -q core trinity_app.py trinity_classic.py trinity_cli.py trinity_server.py`
- `python3 -m pytest -q tests/test_chat_attachments.py tests/test_workspace_context.py tests/test_trinity_bridge.py tests/test_cli.py tests/test_ui_modes.py`
- `bash -n install_linux.sh`
