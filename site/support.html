Ein Problem melden

Support und Datenschutzkontakt: mathias@mathias-engel.de.

Alternativ: GitHub Issues öffnen. Gib App-Version, Betriebssystem, Betriebsart und eine kurze reproduzierbare Beschreibung an. Keine Tokens, Passwörter, private Gespräche oder vollständigen Konfigurationen posten. GitHub Issues sind öffentlich.

Companion-App

Das Companion-Repository bleibt privat. Die kostenlose Veröffentlichung für iPhone und iPad im regulären App Store wird vorbereitet. Ein Store-Link ist erst nach Apples Review und Veröffentlichung verfügbar. Die Desktop-Downloads ersetzen keine App-Store-Installation auf iPhone/iPad.

Zum Start sind keine Abos oder In-App-Käufe vorgesehen. Die KI-Funktionen benötigen einen eigenen erreichbaren Trinity-Server und geeignete Modelle oder Zugänge. Optionale externe Anbieter können separat Kosten berechnen.
