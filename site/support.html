Support & Installation

Desktop-Downloads, Hardwareanforderungen und Sicherheitshinweise findest Du in der Installationsanleitung.

Ein Problem melden

GitHub Issues öffnen. Gib App-Version, Betriebssystem, Betriebsart und eine kurze reproduzierbare Beschreibung an. Keine Tokens, Passwörter, private Gespräche oder vollständigen Konfigurationen posten. GitHub Issues sind öffentlich.

Companion-App

Das Companion-Repository bleibt privat. Ein Unlisted-App-Store-Link ist erst nach App Review und Apples separater Freigabe verfügbar. Die Desktop-Downloads ersetzen keine App-Store-Installation auf iPhone/iPad.
